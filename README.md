# Prolog Web Studio

Интерактивная студия Prolog с редактором базы знаний и консолью запросов. Tau Prolog выполняет программу в Web Worker браузера.

- Редактор `.pl` с номерами строк, подсветкой синтаксиса и загрузкой кода через Ctrl+Enter.
- Консоль `?-` с перебором решений, историей запросов и выводом ошибок.
- Пять готовых программ, импорт и экспорт `.pl`, светлая и тёмная темы.

## Запуск в Docker

Требуются работающий Docker и Docker Compose v2. Выполните команду из корня репозитория.

```sh
docker compose up -d
```

Откройте [Prolog Web Studio](http://127.0.0.1:8086/). Compose публикует сервис `frontend` только на локальном интерфейсе. Node.js собирает приложение, а Nginx отдаёт статические файлы из итогового образа.

После изменения исходников пересоберите сервис.

```sh
docker compose up -d --build
```

Чтобы остановить студию, выполните `docker compose down`.

## Первый запрос

В готовом примере «Генеалогическое древо семьи» выполните в консоли `father(X, ilya).` и получите `X = artem`. Запрос `ancestor(X, ilya).` возвращает несколько ответов. Нажмите «Следующее решение (;)» или клавишу `;` в пустой строке ввода, чтобы продолжить поиск.

Для проверки своей базы знаний вставьте в редактор два факта.

```prolog
color(red).
color(blue).
```

Нажмите «Загрузить код» и выполните `color(X).`. Консоль последовательно вернёт `X = red` и `X = blue`.

## Разработка

Для локальной разработки требуется Node.js 22.12 или новее.

```sh
npm ci --prefix frontend
npm run dev --prefix frontend
npm run lint --prefix frontend
npm run build --prefix frontend
```

Сервер разработки открывается на [порту 5174](http://localhost:5174/). Сборка записывается в `frontend/dist`.
